# Установщик для Windows

Установщик ставит нормоконтроль для текущего пользователя, включая отдельный Python,
Tcl/Tk и Python-зависимости. Если подходящий Wordcraft уже установлен, программа
использует его; иначе Wordcraft загружается из закреплённого официального релиза
и распаковывается рядом с программой. Установленные в системе Python и
Wordcraft не заменяются. Права администратора для стандартной установки не нужны.

Поддерживается Windows 10/11 x64. Это сборка для 64-разрядных Intel/AMD; отдельного
установщика для Windows ARM64 или x86 пока нет.

## Установка

1. Запустите `Normokontrol-<версия>-windows-x64-setup.exe`.
2. Выберите папку установки и нужные ярлыки.
3. Дождитесь проверки окружения и, при необходимости, загрузки Wordcraft. Для его
   автоматической загрузки нужен доступ к GitHub.
4. Запустите программу из меню «Пуск» или с рабочего стола, если выбрали ярлык.

Стандартная папка — `%LOCALAPPDATA%\Programs\WordcraftNormokontrol`. Отдельно
устанавливать Python, pip, Tcl/Tk или PyMuPDF пользователю не требуется.
Скрипты и данные программы расположены в папке установки, Python — в `runtime`,
Wordcraft — в `wordcraft`, если установщик загрузил собственную копию.
Существующие компоненты проверяются отдельно: доступность системного Python
не считается доказательством наличия Tcl/Tk, PyMuPDF или Wordcraft. Собственный
runtime устанавливается независимо от системного Python.

Для рамки и штампа по умолчанию используется **Times New Roman**: надписи — 9 пт,
шифр — 16 пт. ISOCPEUR не требуется. Файлы шрифтов в установщик не включаются:
используются шрифты Windows. При нестандартном составе Windows проверьте результат
диагностики и фактическое отображение штампа в PDF.

Установщик проверяет подготовленное окружение и сохраняет `install-report.json`
в папке программы. Сохраните этот отчёт и журнал установки, если возникает ошибка.
Отчёт об установке не заменяет проверку оформления конкретного документа.

## Установка без загрузки Wordcraft из сети

Скачайте заранее официальный portable ZIP **той версии Wordcraft, которая указана
в [dependencies.json](dependencies.json)**. Передайте путь установщику:

```powershell
.\Normokontrol-1.5.0-windows-x64-setup.exe /WORDCRAFTARCHIVE="C:\Downloads\wordcraft-0.16.0-windows-x64-portable.zip"
```

Имя установщика в примере замените именем собранного файла. Архив Wordcraft
обязательно сверяется с закреплённой SHA-256. Другой релиз или изменённый архив
не принимается. После подготовки EXE и подходящего ZIP доступ к сети при такой
установке не требуется.

Для обычной установки отдельно скачивать архив не нужно. При отсутствии подходящего
Wordcraft установщик загружает его сам, до копирования файлов программы. Ошибка сети или контрольной суммы прерывает
этот этап; повторите установку после устранения причины.

## Тихая установка и диагностика

```powershell
$setup = ".\Normokontrol-1.5.0-windows-x64-setup.exe"
Start-Process -FilePath $setup -Wait -ArgumentList @(
  '/VERYSILENT', '/SUPPRESSMSGBOXES', '/NORESTART',
  '/LOG="C:\Temp\normokontrol-install.log"'
)
```

Для автоматизации проверяйте код завершения процесса: ненулевой код означает, что
успешная установка не подтверждена. Параметр `/DIR="C:\Apps\Normokontrol"` меняет
папку назначения; `/WORDCRAFTARCHIVE="C:\Downloads\wordcraft.zip"` задаёт локальный
архив. Если нужно использовать конкретную существующую установку Wordcraft,
передайте `/WORDCRAFTCLI="C:\Apps\WordCraft\wordcraft-cli.exe"`: установщик должен
проверить её перед использованием. Не используйте папку с посторонними файлами
как папку установки.

Проверить окружение установленной программы можно её собственным Python:

```powershell
$appDir = "$env:LOCALAPPDATA\Programs\WordcraftNormokontrol"
& "$appDir\runtime\python.exe" "$appDir\normokontrol.py" --agent doctor
```

В JSON-ответе проверяйте и `ok`, и `data.ready`. `ok: true` означает выполнение
диагностики; при `ready: false` прочитайте `data.checks`. Режимы JSON и MCP описаны
в [руководстве интерфейса агентов](../references/agent-interface.md).
Для MCP используйте абсолютные пути к `runtime\python.exe` и корневому
`normokontrol.py` с аргументом `--mcp`.

## Обновление и удаление

Для обновления установленной EXE-версии нажмите **Проверить обновления** в программе:

1. Проверяется последний официальный выпуск GitHub Releases и его версия.
2. Если опубликованы подходящий версионный EXE и файл SHA-256, программа предложит
   обновление, скачает установщик и проверит его контрольную сумму.
3. После проверки откроется обычный мастер установки, а окно нормоконтроля закроется.
   Пройдите мастер до конца, чтобы завершить обновление.

Сохранённые реквизиты, локальные настройки и пользовательские результаты
сохраняются. Если удобнее, скачайте новый EXE самостоятельно и запустите его в ту
же папку, предварительно закрыв нормоконтроль.

Коммит в `main` не равен выпуску обновления для EXE-установки. Пока версия не
опубликована в GitHub Releases с версионным EXE и SHA-256, установленная программа
не предлагает её как доступное обновление. При отсутствии выпуска или нужных
файлов проверка не должна подменять установщик ZIP-архивом исходников.

Маркер `.normokontrol-installed.json` отличает установку EXE от распакованного ZIP.
Кнопка **Проверить обновления** выбирает канал по типу установки: EXE-копия получает
проверенный установщик из GitHub Releases, ZIP-копия сохраняет прежнее обновление
исходников из `main`. Для EXE-копии исходники из ZIP не применяются: новые версии
Python-зависимостей и Wordcraft обновляются вместе с программой через установщик.

Удаление доступно через параметры приложений Windows и `unins000.exe` в папке
установки. Оно удаляет установленные файлы и собственные каталоги зависимостей.
Внешняя установка Wordcraft, выбранная для повторного использования, не удаляется.
Пользовательские документы и результаты обработки не входят в состав программы.
Не храните личные файлы внутри `runtime` и `wordcraft`: это служебные каталоги.

## Сборка из исходников

Сборка выполняется на Windows x64. Для самого сборщика нужен доступный Python 3.12+
и интернет. Запустите из корня репозитория:

```powershell
python installer/build.py
```

Сборщик использует закреплённые URL и SHA-256 из `installer/dependencies.json`.
На текущей конфигурации это:

| Компонент | Версия | Назначение |
|---|---|---|
| CPython / python-build-standalone | 3.12.16, сборка 20261026 | Отдельный переносимый Python с Tcl/Tk |
| PyMuPDF | 2.0 | Чтение и проверка PDF |
| Inno Setup | 6.7.4 | Компилятор EXE-установщика в portable-режиме |
| Wordcraft | 0.16.0 | Portable-дистрибутив, который установщик получает с GitHub |

Python-пакеты и все транзитивные зависимости закреплены отдельно в
[requirements-lock.txt](requirements-lock.txt): точные версии и SHA-256 wheels.
Загрузка и установка выполняются pip с `--require-hashes`. При изменении набора
зависимостей обновляйте lock-файл вместе с манифестом; сборка должна отклонять
неизвестный или изменённый wheel. Сведения об установленных пакетах и контрольных
суммах также сохраняются в `THIRD_PARTY/requirements-lock.txt` готовой программы.

Сборщик не использует системный Python как runtime поставляемой программы.
Не заменяйте `python-build-standalone` обычным embeddable ZIP от python.org:
в нём нет полного Tcl/Tk, необходимого GUI.

Рабочие файлы создаются в `build/installer`, кэш загрузок — в `build/downloads`.
Они не предназначены для Git. Для подготовки файлов без компиляции используйте:

```powershell
python installer/build.py --stage-only
```

Для сборки и предварительной загрузки Wordcraft в кэш:

```powershell
python installer/build.py --download-wordcraft
```

Предварительно загруженный ZIP можно передать EXE через `/WORDCRAFTARCHIVE` для
проверки установки без повторного сетевого запроса. При изменении версий обновляйте
в манифесте одновременно URL, версию и контрольную сумму. Не отключайте проверку
SHA-256 ради продолжения сборки.

Результат:

```text
dist/
  Normokontrol-<VERSION>-windows-x64-setup.exe
  Normokontrol-<VERSION>-windows-x64-setup.exe.sha256
```

Контрольная сумма рядом с EXE позволяет проверить целостность полученного файла.
Она не заменяет цифровую подпись издателя. Сборка в репозитории сама по себе не
подписывает установщик сертификатом и не гарантирует отсутствие предупреждения
Windows SmartScreen.

## Проверка перед публикацией

Проверьте установку в отдельную папку, а перед выпуском — также на чистой Windows
без заранее установленных Python и Wordcraft. Минимальная проверка:

1. Сборка EXE и проверка его контрольной суммы.
2. Обычная установка с загрузкой Wordcraft и установка с `/WORDCRAFTARCHIVE`.
3. Успешный `doctor` через поставляемый Python и создание окна Tcl/Tk.
4. Проверка и оформление тестового DOCX с получением PDF и отчётов.
5. Повторная установка с сохранением настроек и результатов.
6. Удаление с сохранением пользовательских документов.

Workflow [installer.yml](../.github/workflows/installer.yml) запускается вручную
через GitHub Actions. Он собирает EXE, проверяет тихую установку и диагностику,
проверяет Tcl/Tk, создаёт тестовый DOCX и PDF через установленную программу и
сохраняет установщик, контрольную сумму и журналы как artifacts.
Workflow не создаёт GitHub Release и не публикует EXE автоматически.

Полный локальный прогон собранного EXE (тестовая папка создаётся в `build/`):

```powershell
python installer/smoke.py
```

Дополнительно проверить повторное использование уже установленного редактора:

```powershell
python installer/smoke.py --external-wordcraft "C:\Program Files\ArtCraft\WordCraft\wordcraft-cli.exe"
```

Проверяются автономная установка, реальное создание DOCX/PDF, повторная установка
с обнаружением приватного Wordcraft, сохранение настроек и документов после
удаления, а также отказ до установки при неверном SHA-256 архива. Тестовую
установку удаляет её собственный деинсталлятор; журналы остаются в `build/smoke-…`.

## Лицензии и внешние компоненты

Wordcraft загружается из официального релиза `storytold/wordcraft`. Portable-архив
распаковывается вместе с сопровождающими лицензиями и уведомлениями. В private
Python сохраняются лицензии его дистрибутива и установленных Python-пакетов.
Шрифты Windows и ISOCPEUR в установщике не распространяются.

Условия внешних компонентов не заменяются лицензией исходников нормоконтроля.
При смене состава поставки проверяйте лицензии и сохраняйте соответствующие
license/notice-файлы в итоговом дистрибутиве.
